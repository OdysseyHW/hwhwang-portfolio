## 수정 권고
### R1 / 중간: 글자 확대가 대형 제목에 반영되지 않음
위치: src/components/Hero.astro:187, 196, 306.
REQUESTS의 200% 글자 확대 조건에 대해 현재 테스트는 겹침만 검사하고 실제 글자 확대 여부를 확인하지 않는다.
html font-size를 200%로 변경한 동일 화면 측정:
- 390×844: 제목 42.9px → 45.095px (약 1.05배)
- 1440×900: 122.4px → 128px (약 1.05배)
- 844×390: 58.5px → 58.5px (변화 없음)
원인: vw/cqi/svh 크기 상한이 rem 확대를 제한한다.
수정: 사용자 글자 확대가 반영되는 rem 중심의 크기 규칙을 적용하고, 화면을 맞추기 위해 글자를 축소하는 대신 줄바꿈과 히어로 높이 증가를 허용한다. 3행 고정은 기본 상태에서만 유지해도 된다.
검증: 같은 너비에서 기본/확대 제목의 실제 크기 증가 및 콘텐츠 접근성을 검사한다. html 크기 변경은 설정 변경의 재현 검사이며 실제 브라우저 확대 기능의 완전한 대체가 아니다.

### R2 / 중간: 낮은 가로 화면에서 영상 제어 버튼이 첫 화면 아래로 밀림
위치: src/components/Hero.astro:215 및 306 근처의 낮은 화면 배치.
844×390 기본 화면에서 정지 버튼 top=373.86, bottom=417.86, 화면 높이=390. 제공한 home-mobile-landscape-844.jpg에서도 일부만 보인다.
스크롤하면 접근 가능하므로 기능 자체가 사라진 것은 아니다. 다만 움직이는 배경의 항상 제공되는 제어라는 취지와 첫 화면 조작성이 약해진다.
수정: 낮은 가로 화면에 한해 영상 제어를 히어로 상단의 헤더 아래 또는 CTA와 함께 보이는 위치로 배치한다. 제목을 더 작게 만드는 방식으로 R1을 악화시키지 않는다. 전체 사이트에 고정해 다른 콘텐츠를 가리지 않는다.
검증: 844×390, 667×375에서 첫 화면의 정지 버튼 전체가 보이고 44px 영역과 다른 요소가 겹치지 않는지 확인한다.

- 샘플 포스터/WebM 재사용: 현 단계에 적절하다. 최종 공개 전 실제 iOS 영상 확인과 필요 시 MP4 제공이 남는다.
